# 参考候选词与图片缓存

来源：项目所有者提供的「盲拧联想词 240819.xls」，Sheet1。

原文件保持不变。源文件SHA-256、各编码的单元格位置及完整词语保存在 src/data/BLDCandidates.json。

## 提取规则

- 列表头为第一个编码字母，行表头为第二个；例如B3为AB「安倍」，C2为BA「保安」。表头h统一为编码H，跳过中间重复的行标签列。
- 共有576组编码，565组有候选词；按原表保留615个候选词，去重后613个不同词语。每组1～3个，不补成5个，也不按拼音重写原表。
- 斜线、反斜线用于拆分多个候选词；括号内斜线保留为说明，例如ON的「on（开机/向前）」。原词中的英文、括号、特殊字符与拼写保留。
- DN、DO、DP、DQ、DR、DS、DT、DW、DX、DY、DZ为原表空白；U、V未出现在原表。没有候选词时仍可自行输入，随机编码与角棱排除规则保持原逻辑。

## 缓存与显示

- 613个不同词语均已准备图片，共1827个图片候选；按图片内容去重后为1791个本地文件，约54MB。
- 图片保存在 public/assets/memory，构建时复制到 dist/assets/memory。src/data/BLDCandidateImages.json保存图片地址、缓存路径、搜索词义及发布网页。
- 参考图片来自Bing的严格筛选搜索结果。英文提示、作品角色等使用更明确的搜索关键词，原候选词不变。搜索图片仍可能有歧义，首次输入后展示缓存图供选择；个人已确认的配图优先。
- 输入前只呈现编码和候选文字，不创建图片元素或预请求图片。点击候选词只填入输入框，提交后才显示配图。
- 参考词独立于个人词库。提交后才添加或复用个人词条，选图后保存缓存路径；导入、导出时保留该路径。内置图片随项目提供，个人备份不重复嵌入图片字节。
- 其他联网搜索图片在首次显示后另存至 .cache/memory-images，重启本地服务后仍可使用。此运行缓存不打入发布包。

## 维护

开发时可用安装了xlrd的Python运行 `python scripts/import-mnemonics.py "词表文件.xls"` 重新提取。该步骤仅用于准备数据，应用运行不依赖Python或原始XLS。

运行 `node scripts/cache-mnemonics.cjs` 可继续补齐缺失图片。已下载的图片会复用；搜索失败的词会记录并在下次重试，全部完成后运行 `npm run build`。
