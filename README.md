# CUBE / 个人魔方训练器

GitHub Pages地址：https://pxf0429.github.io/cube-trainer/

一个独立的个人魔方训练器，集成盲拧编码记忆与 EOLR 识别训练。界面以蓝白为基础，粉色点缀主要操作与选中状态。项目可以单独移动、安装、运行，不依赖旁边的 roux-trainers 文件夹。

打开后进入训练首页，可选择 EOLR 识别或盲拧记忆。「编码记忆」随机呈现编码和参考候选词，输入或选择联想词并按 Enter 后才显示图片。个人词库已有图片时优先复用，参考词优先读取项目内缓存的图片供选择，其余新词联网找图。选择后保存，后续优先复用已确认的图片。搜图失败仍保留编码词，支持重试。随机编码来自完整编码范围，空词库也可开始。

## 盲拧记忆

- **编码记忆**：随机编码 → 输入中文词 → 查找已有图片或自动搜索入库。支持通用A–Z编码、Speffz／彳亍角棱编码与自定义数字编码；角棱范围排除同一块上的编码组合。
- **参考候选词**：采用用户提供的「盲拧联想词 240819.xls」，原样提取615个候选词（613个不同词语），按原表数量展示，不补造词语。编码的第一个字母来自列表头，第二个来自行表头；空白及未收录编码可自行输入。参考候选不会自动加入个人词库或改动复习进度。
- **提前缓存配图**：全部参考词准备了本地图片候选，文件位于 public/assets/memory，构建时一同复制到 dist。输入前不显示图片，也不请求图片资源；首次选定后随个人词条保存，重启后可直接使用。缓存准备记录见 docs/BLD_REFERENCE.md。
- **编码词库**：单词录入、批量录入、搜索、编码矩阵和多联想词。每个词可保存独立图片、来源与联想场景。
- **记忆练习**：看编码想词、看词想编码、看图想编码、串联记忆；答题后更新正确率、薄弱词与复习间隔。
- **编码方案**：角块与棱块各24个贴纸编码，提供展开图；自定义编码可使用1–3位字母或数字。
- **图片**：优先通过 Wikidata 的准确词条及其代表图片匹配，如「苹果」优先水果而非公司；「破伞」等短语保留原中文，通过 Bing 搜索候选图。仅词条代表图用于自动配图，普通搜索结果需要手选。首页「图片不对？重选」可直接纠正旧配图，候选图标注词义或标题。也支持更换关键词和自选https图片地址。
- **备份**：导出词库、图片链接、来源、编码方案和复习进度；可合并导入本训练器或参考站的 `letterTableData.json`。备份保存图片链接，不包含图片二进制文件。

本地运行时，内置图片服务会使用现有系统网络设置，只访问指定的公开图片与词义服务，不需要API密钥。百科接口请求排队并缓存，已加载的远程图片另存到 .cache/memory-images，服务重启后继续复用。参考词内置图片在断网时仍可显示；首次搜索新词或未缓存的远程图需要网络。静态部署的搜索使用公开CORS接口，中文搜索通道需要运行本地服务。

侧边栏的「训练首页」汇总功能，「EOLR识别」保留原有中文规则、收藏、记录与魔方配色。

## 启动

安装 Node.js 20 或更高版本，然后在 PowerShell 中运行：

```powershell
cd D:\eolr_execise\eolr-trainer
npm install
npm start
```

当前电脑的依赖已准备好，可直接运行 npm start。浏览器打开 http://localhost:5173。按 Ctrl+C 停止。端口被占用时：

```powershell
$env:PORT=5174
npm start
```

## 怎么练

- **随机练习**：选择一个或多个 EO 大类；默认全部。先判断大类，再观察 LR，按空格揭晓。揭晓前不显示当前答案。
- **转换情形**：解法中的转换目标可点击查看对应识别与做法，并可继续查看后续转换、返回上一情形；关闭弹窗回到原题。
- **分类顺序**：左侧EO分类按大类转换依赖排序，优先学习前置大类。统计说明见 docs/EOLR_DEPENDENCIES.md。
- **中心朝向**：所有初始练习打乱均要求顶底色的中心位于顶面和底面，允许上下互换，默认是白黄中心。随机出题从89,280个符合要求且有中文规则的状态中抽样，保留全部51种情形。
- **情形图鉴**：按EO大类分组，对照情形名称与识别条件；支持关键词搜索，展开条目查看处理思路。
- **定向练习**：在「情形图鉴」中展开情形，点击「练习这一情形」。每次仍会产生新的合法随机状态。
- **收藏复习**：星标保存当前题目的具体打乱；「收藏复习」重复练这些题。
- **虚拟魔方**：立体视图会将当前看不到的三个面映射到旁边，保留各面的贴纸方向；拖动旋转时映射面随视角更新。支持六面展开、聚焦 LR、撤销与重置操作。
- **魔方配色**：点击魔方下方的「配色」，设置左桥、右桥和底面颜色。左右桥保持对面关系，底色可选六种标准色，其他面按真实魔方配色自动匹配，共24种朝向。设置即时生效并自动保存在当前浏览器，可一键恢复默认。
- **自定义打乱**：支持仅包含 U / M 转动的一条打乱，按实际状态分类。顶底色中心朝向前后面、或EO已完成时会提示重新输入。
- **练习记录**：揭晓即保存为「已查看」，再标记「已掌握」或「还需练习」时更新同一条记录，不重复计数。掌握率为你自行标记的结果；时间为出题到揭晓的时长。
- **备份**：「练习记录」支持导出和合并导入记录与收藏。记录保存在当前浏览器、当前地址，localhost 和 127.0.0.1 的记录独立。

中心方向不符合当前要求的旧收藏仍保留在备份中，但不会进入收藏复习出题池；已有练习历史保留。

| 快捷键 | 操作 |
| --- | --- |
| Space | 揭晓 / 下一题 |
| Enter | 重置当前魔方 |
| J / F | U / U' |
| K / I（或 D / E） | M / M' |
| Shift + J / K | U2 / M2 |
| ← | 撤销一步 |
| 1 / 2 | 已掌握 / 还需练习，并下一题 |

识别与处理按原笔记展示，保留所需的 U、U' 或 U2 顶层调整提示，不添加整颗转体要求。答案对应初始打乱，而非手动操作后的新情形。

## 构建与验证

GitHub仓库的main分支更新后，`.github/workflows/pages.yml`会自动执行检查、测试和构建，再发布dist到GitHub Pages。候选图片一同部署，资源使用相对路径，支持仓库子目录地址。线上不运行本地Node图片服务；新增词语使用Commons公开搜索，也可使用自选图片地址。

```powershell
npm run check
npm test
npm run build
```

dist 是完整静态网页，可部署在普通静态托管服务中，支持子目录。构建后没有运行时第三方依赖，无远程字体、统计脚本或联网数据请求。请通过 HTTP 服务访问，不能直接双击 index.html（模块与后台出题器需要 HTTP）。

开发服务会在源文件改变时重新构建，浏览器手动刷新后生效。npm start 与 npm run dev 等价。

## 结构

- src/app.ts、styles.css：独立中文界面和交互。
- src/CubeView.ts：CSS 立体魔方与六面展开，不依赖 WebGL。
- src/Icons.ts、favicon.svg：统一的蓝粉双色操作图标与立体魔方应用标志。
- src/lib/CubeLib.ts、Defs.ts、Math.ts：原项目的魔方基础模型。
- src/lib/EOLRCases.ts：先判断 EO 大类，再按本类中文条件识别。
- src/lib/LSEEngine.ts、generator.worker.ts：在后台遍历 184,320 个合法 LSE 状态，在所选范围内随机抽样并生成可复现的 U / M 打乱，不用固定示例冒充随机题。
- src/data：51 条原始中文笔记和核对后的规则。
- tests：独立运行的识别、随机出题、存储及输入验证测试。
- docs/EOLR_RULE_AUDIT.md：51 条识别规则的逐项核对记录，规则含义与位置栏差异说明。

本版聚焦这 51 条 EOLR 中文识别情形；原项目的其他训练模式、EOdM、EOLRb 和多求解器比较不包含在内。
